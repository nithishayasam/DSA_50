# DSA_50

50 days of DSA practice in C++.

## Progress
| Day | Topic | Problem | Approach | Time |
|-----|-------|---------|----------|------|
| 1 | C++ basics | [day01](day01/) | Variables, data types, operators | - |
| 2 | Conditionals, loops, patterns | [day02](day02/) | if/else, while loop, for loops, pyramid pattern | - |
